The Alphabet & Script

28 letters, no capitals, written right to left, and every letter reshapes itself depending on where it sits in a word. Here is exactly how, and exactly why.

How to read this page

Every Arabic word below is shown with a transliteration in monospace directly under or beside it — a Latin-letter approximation of the sound, using a small set of marks (macrons for long vowels, an underdot for emphatic consonants) so one Latin letter reliably maps to one Arabic sound. Toggle transliteration off with the button in the top bar once you can read the script on its own — that's the actual goal.

Why letters change shape

Arabic script is cursive by default — even printed text — so most letters physically connect to their neighbors, the way joined-up handwriting connects English letters. A connecting letter therefore has up to four forms: isolated (standing alone), initial (starting a word, connects only forward), medial (middle of a word, connects both directions), and final (ending a word, connects only backward). The letter's core identity — its dots and basic skeleton — never changes; only the connecting "arms" appear or disappear.

Six letters that refuse to connect forward
ا د ذ ر ز و (alif, dāl, dhāl, rāʾ, zāy, wāw) never connect to the letter that follows them, even in the middle of a word. If one of these appears mid-word, the next letter simply starts fresh in its own isolated-style form. This is why you'll sometimes see a visual "break" inside an otherwise joined Arabic word — it's not a space, it's one of these six letters doing its job.

The dots (iʿjām) — the detail nothing else covers

Several letters share an identical base shape and are distinguished only by small dots (نقط nuqaṭ) placed above or below. This is the single most literal answer to "cover every tiny dot" — get the dot count or position wrong and you've written a different letter:

  • ب ت ث — same base curve. ب = one dot below, ت = two dots above, ث = three dots above.
  • ج ح خ — same base hook. ح = no dot, ج = one dot below, خ = one dot above.
  • د ذ — same base shape. د = no dot, ذ = one dot above.
  • ر ز — same base shape. ر = no dot, ز = one dot above.
  • س ش — same base shape (with three "teeth"). س = no dot, ش = three dots above.
  • ص ض — same base shape. ص = no dot, ض = one dot above.
  • ط ظ — same base shape. ط = no dot, ظ = one dot above.
  • ع غ — same base shape. ع = no dot, غ = one dot above.
  • ف ق — historically distinguished by dot count (one vs. two above); in most modern printing ف keeps one dot and ق keeps two, though some regional (especially Maghrebi) handwriting reverses or alters this.
Two more marks that aren't "dots" but act like them
Hamza (ء) is a small hook, not a dot, representing a glottal stop; it can sit on its own or perch on a carrier letter — ا, و, or ي — chosen by vowel-harmony rules explained on the phonetics page. Tāʾ marbūṭa (ة) looks like ه with two dots added, and only ever appears at the end of a word, almost always marking feminine gender.

Sun letters and moon letters

This matters the moment you use the definite article ال (al-, "the"). Arabic's 28 letters split into two behavioral groups:

  • Moon letters (14): ا ب ج ح خ ع غ ف ق ك م ه و ي — the ل of al- is pronounced normally: القمر al-qamar ("the moon").
  • Sun letters (14): ت ث د ذ ر ز س ش ص ض ط ظ ل ن — the ل is not pronounced; instead the following consonant doubles: الشمس is pronounced ash-shams, not al-shams, even though it's still spelled with the ل.
Memory hook
قمر (qamar, "moon") itself starts with a moon letter, and شمس (shams, "sun") itself starts with a sun letter — the category names are self-demonstrating.

Arabic-Indic numerals

Digits are written left to right even though text reads right to left — the one place direction flips inside an Arabic sentence.

Western0123456789
Eastern Arabic-Indic٠١٢٣٤٥٦٧٨٩

Most of the Arab world east of Egypt uses these forms daily; the Maghreb (Morocco, Algeria, Tunisia, Libya) generally uses the same digits as English (0–9).
