Sources & Contributing

Where this guide's grammar claims come from, and how to submit corrections, new sections, or new projects to the repository.

Reference sources

This guide simplifies and restructures well-established descriptive grammar of Modern Standard Arabic for a practical, self-taught audience. For deeper or more academic treatment, these are solid starting points:

Wikipedia — Arabic grammar A thorough, well-cited overview of case, mood, and morphology — good for cross-checking specific claims. Wiktionary — Arabic entries Root-organized dictionary entries with conjugation tables for individual verbs. FSI Modern Standard Arabic (Live Lingua) The (public-domain) US Foreign Service Institute course — dense but authoritative, free to redistribute. Madina Arabic A widely-used structured course for Classical/MSA grammar fundamentals, iʿrāb included. Wikipedia — Arabic phonology IPA-referenced detail on articulation points and emphatic consonants. Quranic Arabic Corpus Word-by-word morphological tagging — a good way to see root-and-pattern analysis applied at scale.

This list is intentionally short and high-quality rather than exhaustive — pull requests adding well-vetted sources are welcome.

Contributing to arabic.ai

This project is meant to be forked, corrected, and extended. A few ground rules that keep it useful:

  1. Every grammar claim needs a source or a native-speaker sanity check. Open an issue if you're not sure where to verify something.
  2. Keep transliteration consistent. Use the mapping in js/data.js (TRANSLIT_MAP) rather than inventing a new romanization per page.
  3. No build step, on purpose. Plain HTML/CSS/JS keeps the barrier to contributing low — please don't introduce a bundler without discussing it in an issue first.
  4. New pages should follow the existing shell. Copy the topbar/sidebar markup from an existing page exactly so navigation stays consistent.

Running it locally

terminal
git clone https://github.com/<your-username>/arabic.ai.git
cd arabic.ai
# any static file server works — e.g.:
npx serve .
# then open the printed localhost URL

A local server (rather than opening index.html directly) avoids browser restrictions on loading local JS modules.
