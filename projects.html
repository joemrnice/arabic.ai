Build: Projects

Three small, dependency-free JavaScript tools, live on this page and fully readable in js/projects-demo.js and js/data.js. Fork the repo and extend any of them.

Project 1 — Arabic → Latin transliteration converter

A live text converter that walks an Arabic string character by character and looks each one up in a translation table. It's deliberately naive — a good first exercise is making it context-aware (for example, handling ال + sun letters correctly, per the sun/moon rule).

js/projects-demo.js — excerpt
function convert(text) {
  return [...text]
    .map(ch => (ch in TRANSLIT_MAP ? TRANSLIT_MAP[ch] : ch))
    .join("");
}

input.addEventListener("input", () => {
  output.textContent = convert(input.value) || "—";
});
Ways to extend this
Handle tāʾ marbūṭa contextually (silent vs. "-at"), collapse a hamza-carrying letter down to a single ʾ symbol, or add a reverse mode (Latin → Arabic) using a fuzzy best-match lookup instead of exact keys.

Project 2 — Root expander

Pick a triliteral root and see its derived word family rendered from data, the same renderer that powers the "root card" component used throughout this site.

js/data.js — a root entry
{ root: ["ك","ت","ب"], gloss: "the idea of writing", words: [
    { ar: "كَتَبَ", translit: "kataba", en: "he wrote" },
    { ar: "كِتَاب", translit: "kitāb",  en: "book" },
    { ar: "مَكْتَب", translit: "maktab", en: "desk / office" },
    { ar: "كَاتِب", translit: "kātib",  en: "writer" },
    { ar: "مَكْتَبَة", translit: "maktaba", en: "library" },
]}
Ways to extend this
Add more roots to the ROOTS array in js/data.js — no other code changes needed, since the renderer is fully data-driven. A bigger upgrade: generate derivations programmatically from a root plus a list of known patterns, instead of hand-listing words.

Project 3 — Verb conjugation drill

Pulls a random pronoun from the VERB_KATABA paradigm (see the full table) and checks your typed answer, ignoring diacritics so you're not penalized for typing without full vowel marks.

js/projects-demo.js — excerpt
function stripDiacritics(s) {
  return s.normalize("NFC").replace(/[\u064B-\u0652\u0670]/g, "").trim();
}

checkBtn.addEventListener("click", () => {
  const guess = stripDiacritics(inputEl.value);
  const answer = stripDiacritics(current.ar);
  statusEl.textContent = (guess === answer)
    ? "✓ Correct — " + current.ar
    : "Answer: " + current.ar;
});
Ways to extend this
Add more Form-I roots as separate paradigm objects, track a running score in localStorage the way the transliteration toggle already does in js/main.js, or add a "hint" button that reveals just the prefix/suffix.

Open project ideas for the repo

Good first issues for arabic.ai if you're forking it:

  • Audio pronunciation: attach recorded or synthesized audio to each alphabet flashcard.
  • Handwriting practice: a canvas-based tracing exercise for each letter's four forms.
  • Spaced repetition: turn the vocabulary tables into a proper SRS deck with localStorage-backed review intervals.
  • Broken-plural predictor: a small pattern-matcher that guesses a noun's plural pattern from its singular shape.
  • i'rāb visualizer: color-code a pasted sentence by grammatical case once the user marks each word's role.
