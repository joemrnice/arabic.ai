The idea this whole site is built around
Almost every Arabic word grows from a three-letter root that carries a core meaning. Change the vowel pattern or add a prefix/suffix, and the root becomes a verb, a person, a place, or a tool. Learn the root system early and vocabulary stops being a list to memorize — it becomes a set of patterns you can predict.

"Cover every tiny dot" — literally

Arabic's dotting system (إعجام iʿjām) is not decorative: letters like ب ت ث share one skeleton and are told apart only by where their dots sit and how many there are. Get a dot wrong and you've written a different letter, or a different word entirely. This guide treats that literally — the alphabet page has a dedicated section on dot placement, and the Q&A answers the specific "wait, why does this letter have three dots" questions learners actually run into.
